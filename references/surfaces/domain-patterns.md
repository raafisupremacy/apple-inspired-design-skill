# Domain patterns

Starting cues per product domain: the primary task, a fitting color strategy, a signature idea, and the patterns that matter. Treat them as starting points; the user's brand and task win. For an unlisted domain, use the custom-domain process in `../foundations/principles.md`.

| Domain | Primary task | Color strategy to propose | Signature idea | Key patterns |
| --- | --- | --- | --- | --- |
| Finance / banking | check, move, understand money | quiet neutral or tinted + one trusted accent | big balance number, calm charts | summary first, transaction list, clear confirmations, undo/recovery |
| Health / fitness | track progress, stay motivated | category colors; immersive dark for workouts | rings/bars per category, bold metrics | summary dashboard, trends, goals, gentle reminders |
| Food / delivery / lifestyle | discover and order | vivid warm surfaces | appetizing full-bleed photos | shelves, filters, sticky cart, live order status |
| Social / community | read, share, connect safely | tinted neutral; color from user content | content-first feed, expressive reactions | identity, audience/privacy, edit/undo/report/block, moderation and empty feeds |
| Media / music / video | play and browse | immersive dark + artwork-derived color | artwork-led player | shelves, now playing, continuity mini-player |
| Productivity / notes / tasks | capture and organize | quiet neutral + signature accent (Notes-yellow style) | instant capture | lists, smart groups, quick add, keyboard shortcuts |
| Education / kids | learn step by step | vivid, friendly | progress and celebration moments | lessons as cards, progress, streaks without guilt |
| Travel / maps | plan and navigate | tinted, map-led | map as the canvas with sheets on top | search, sheets with detents, itineraries |
| Commerce | choose and buy | product-led color | product stage + configurator | see `commerce.md` |
| SaaS / B2B / dev tools | do repeated work | neutral or tinted; dark option | calm shell + command palette | see `web-app-saas.md` |
| Marketing / company profile | persuade, inform | brand color fields, product-led | hero composition + one motion moment | see `web-marketing.md` |

## Shared rules

- **Onboarding:** lead with value, reach a first success quickly, ask for permissions at the moment of need, allow skip/back, persist progress.
- **Settings and account:** organize by the user's mental model, grouped rows with current values, explicit destructive recovery, clear sign-out consequences.
- **Social participation:** keep actions near the content they affect; make audience, edit, undo, report, and block understandable; handle optimistic updates and failures.
- **Notifications and badges:** informative, not decorative; never use motion or badges just to drive engagement.
