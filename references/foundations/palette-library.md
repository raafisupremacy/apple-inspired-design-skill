# Palette library

Precomputed output of `scripts/palette.py` for agents that cannot run Python or a terminal.
Every palette below passes the generator's contrast floors in light and dark.
Use it only through the fallback steps in `color.md`; when the script can run, run it instead.

Generated by `python scripts/palette.py --write-library`. Do not edit by hand.

Role order in every `light` / `dark` line: bg, surface, surfaceElevated, separator, text, textSecondary, textTertiary, textInverse, brand, accent, accentHover, accentPressed, accentSoft, onAccent, link, focus, success, warning, danger, info.
