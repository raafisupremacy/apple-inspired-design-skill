# Apple-inspired design skill v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the rule-heavy skill into a craft-first, color-free, all-surface Apple-inspired design skill.

**Architecture:** Lean `SKILL.md` router + Design Direction intake; references split into foundations / surfaces / stacks / quality; a stdlib palette generator produces accessible light/dark tokens from any seed color and also renders the bundled starter tokens.

**Tech Stack:** Markdown, Python 3.11 standard library (`unittest`), static CSS/JSON.

**Spec:** `docs/superpowers/specs/2026-11-26-skill-v2-design.md`

## Global Constraints

- No third-party dependencies, network access, install hooks, or runtime services.
- Never claim official Apple design; never bundle SF fonts / SF Symbols for non-Apple platforms.
- The user's seed color is preserved exactly as the `brand` role; UI roles are adjusted only for contrast.
- Contrast floors per theme: text ≥ 7:1, textSecondary ≥ 4.5:1, textTertiary ≥ 3:1, link ≥ 4.5:1, onAccent on accent ≥ 4.5:1, semantic colors ≥ 4.5:1 — against bg, surface, and surfaceElevated.
- Default theme is light unless the strategy is `immersive` or the user asks for dark.

## Review Focus

- Low-chroma seeds (`#888888`, `#FFFFFF`, `#000000`) must still produce valid, passing palettes.
- Very light seeds (`#FFD60A`) need dark on-accent text; very dark seeds (`#0A1F44`) need a lighter dark-mode accent.
- Malformed input (`"orange"`, `"#12"`) raises `ValueError`; 3-digit hex (`#f60`) is accepted.
- Dark-mode text on `surfaceElevated`, not only on `bg`, meets the floors.
- Starter `tokens.css` must stay byte-identical to what the generator renders from `tokens.json`.

### Task 1: Palette generator

**Files:** Create `scripts/palette.py`, `tests/test_palette.py`

**Interfaces — Produces:**
- `parse_hex(value: str) -> str` (normalized `#rrggbb`, raises `ValueError`)
- `hex_to_oklch(hex: str) -> tuple[float, float, float]`, `oklch_to_hex(l, c, h) -> str` (gamut-clamped by reducing chroma)
- `contrast(a: str, b: str) -> float`
- `STRATEGIES = ("neutral", "tinted", "vivid", "immersive")`
- `build_palette(seed: str, strategy: str = "tinted") -> dict` → `{"seed", "strategy", "defaultTheme", "light": {role: hex}, "dark": {role: hex}, "ramp": {"50".."950": hex}}`
- Roles: `bg surface surfaceElevated separator text textSecondary textTertiary textInverse brand accent accentHover accentPressed accentSoft onAccent link focus success warning danger info`
- `check_palette(palette: dict) -> list[str]` (empty list = all floors pass)
- Renderers: `render_css(p)`, `render_json(p)`, `render_tailwind(p)`, `render_swiftui(p)`, `render_compose(p)`, `render_flutter(p)`, `render_starter_css(tokens: dict)`
- CLI: `python scripts/palette.py SEED [--strategy S] [--format css|json|tailwind|swiftui|compose|flutter|report] [--write-starter]`

- [ ] Tests: roundtrip hex↔oklch within 1/255; `brand == seed`; `check_palette == []` for seeds `#F2643A #FFD60A #0A1F44 #888888 #FFFFFF #000000 #34C759 #7B61FF` × all strategies; invalid inputs raise; 3-digit accepted; immersive `defaultTheme == "dark"`.
- [ ] Run `python -m unittest discover -s tests -v` → fail, implement, pass.
